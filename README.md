# Mindra

**裏は Markdown、表は図。** AI と人間が同じファイルを、それぞれの見え方で共有する Web アプリ。

## コンセプト

| | 見るもの | 扱い方 |
| :--- | :--- | :--- |
| 人間 | マインドマップ・フローチャートなどの図 | 直感で見る・使う |
| AI | Markdown（.md） | 読む・書く |

- データの正本は `.md` ファイルだけ。図は MD から毎回作る「見え方」で、図だけの独自データは持たない。
- AI が MD を書き換えると、人間が見ている図もそのまま変わる。
- 図の種類は差し替え式。最初はマインドマップ、その後フローチャートなど、いろいろな図に広げていく。

## 技術と起動方法

- サーバーなし。HTML / CSS / JS だけで動く。ビルドも実行時の依存もない。
- 対応ブラウザは Chrome / Edge などの Chromium 系（File System Access API を使う）。

起動は、`index.html` をブラウザで開き、「MD ファイルを開く」で .md を選ぶだけです。選んだファイルは、変更すると自動で図が描き直されます。

テストは Node（v18 以上）で次のとおり実行します。

```
npm test
```
